Всем привет! Хочу рассказать о своем проекте универсального биллинга **SaviorBill** (или, скорее, уже ближе к полноценному движку магазина), почему я начал его делать и для кого.

## Как я докатился до жизни такой

Изначально, при желании продавать некоторые цифровые товары и доступы, я решил использовать SHM. Проект в целом хороший, но мне он был неудобен. Хотя сейчас вроде как исправлены те вещи, которые мне не понравились, но я решил написать свое — уж не умею я в Perl ничего быстро под себя дописать.

Взял свой родной стек, который я знаю лучше всего: **Python 3.12, FastAPI, PostgreSQL, Valkey**. Но перфекционизм заставил всё перевернуть и добавить Lua, мультивалютность и многие другие вещи, которые я считал правильными и красивыми.

Проект построен по принципу микросервисов и API First:
- Для работы с услугами (за исключением чистых текстовых цифровых ключей);
- Интеграции с эквайрингами и платёжками;
- Добавления OAuth/OIDC провайдеров;
- Триггеров и работы с почтой;

необходимо лишь написать свой скрипт на языке **Lua**, который исполняется в изолированном контейнере.

---

## Для кого этот проект и для чего подходит?

SaviorBill создавался для владельцев небольших и средних проектов и интернет-магазинов, разработчиков, продающих свои услуги, а также для селлеров и реселлеров.

### SaviorBill подходит для продажи:
- **Цифровых ключей и лицензий** (мгновенная выдача из пулов с блокировкой `SKIP LOCKED`);
- **VPS/VDS хостингов** со встроенным конфигуратором ресурсов (vCPU, RAM, NVMe);
- **SaaS и API-доступов**, подписок на веб-сервисы, Telegram-ботов;
- **VPN и сетевых сервисов** (WireGuard, VLESS, Outline с генерацией QR-кодов);
- **Пополнения балансов сервисов** (например, Steam или OpenRouter);
- **Любых услуг** с гибкими подписками, конфигураторами, фиксированной или произвольной суммой.

## Компоненты системы и стек

- **BillingCore:** API, обработка данных и манипулирование задачами (Python 3.12 + FastAPI);
- **LuaWorker:** исполнение пользовательских Lua-скриптов в изолированной среде (чистый LuaJIT);
- **MediaWorker:** загрузка и раздача медиа с возможностью настройки конвертации через FFmpeg и поддержкой S3 / Cloudflare R2;
- **sbuiSDK:** библиотека для преобразовывания описанных в манифесте Lua-скриптов декларативных схем в UI-формы витрины клиента;
- **PostgreSQL 16:** реляционная база данных и транзакции;
- **Valkey 8:** кэш и потоки задач (Valkey Streams).

## При чем здесь LUA и как он используется?

Lua по своей сути — идеальный встраиваемый язык. Здесь же он используется по прямому назначению: для интеграций.

Все скрипты выполняются в **LuaWorker**, а биллинг передает ему задачи через Valkey Streams.

### Lua и плагины — не одно и то же
* **Lua** предназначен прежде всего для внешних интеграций и бизнес-действий: создать пользователя во внешней панели, проверить платёж или отправить webhook.
* **Плагины**, наоборот, расширяют сам сервер SaviorBill: они могут добавлять Python-код, API-маршруты, миграции, права доступа и обработчики событий.

### Как скрипт понимает, что ему нужно делать?

Каждый Lua-скрипт получает объект `ctx` — изолированный контекст текущей задачи. Структура контекста зависит от типа скрипта:
- `service` (услуги) — имеют действия `create`, `renew`, `stop`, `delete`, `freeze`;
- `payment` (эквайринги) — получают `create`, `callback`, `check`, `refund`;
- `auth` (авторизация) — получают `start` и `callback`;
- `email` — получают `send`.

#### Пример скрипта выдачи услуги:

```lua
-- scripts/services/vpn.lua
function handle(ctx)
  if ctx.action == "create" then
    -- Логика запроса к вашей VPN панели
    return {
      public = {
        subscription = "https://example.com/sub/token123"
      },
      private = {
        username = ctx.user.login
      },
      state = "active",
      expires_at = os.time() + 30 * 86400
    }
  end
end
```

`public` содержит данные, которые показываются покупателю в личном кабинете, `private` — внутренние данные ядра, а `state` и `expires_at` управляют жизненным циклом услуги.

## Быстрый запуск

Для быстрого развертывания достаточно выполнить:

```bash
curl -fsSL https://get.saviorbill.com | bash
```

Установщик скачает актуальный compose-файл, сгенерирует криптографические ключи и запустит платформу.
