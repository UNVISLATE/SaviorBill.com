Спрос на персональные и корпоративные VPN-решения с современными высокоскоростными протоколами шифрования и туннелирования (VLESS, Reality, Trojan) растёт с каждым днём. Однако перед разработчиками и администраторами инфраструктуры часто встаёт практическая задача: **как надёжно связать панель управления нодами с автоматическим приёмом платежей и выдачей доступов без громоздких надстроек?**

В этом руководстве мы с нуля настроим полностью автоматизированный сервис продажи VPN на базе **SaviorBill**, используя готовые модули из нашего каталога:
- Эквайринг [ЮKassa Payment Gateway](/ru/hub/yookassa-payment) (карты МИР, СБП, SberPay);
- Модуль выдачи [Marzban VLESS VPN Delivery](/ru/hub/marzban-vless);
- Декларативный интерфейс выдачи ключей на базе [Server-Driven UI (sbuiSDK)](/ru/docs/sbuisdk-components).

---

## Архитектура решения

Схема автоматизации построена на микро-контрактах:

```
[Покупатель] 
     │ 1. Выбор тарифа в витрине
     ▼
[SaviorBill Core] ─── 2. Создание инвойса ───► [ЮKassa API]
     │                                              │
     │ 3. Моментальный Webhook                      ▼
     │◄─────────────────────────────────── [Покупатель оплачивает через СБП]
     │
     ▼ 4. Запуск задачи в LuaWorker
[LuaWorker] ──────── 5. REST API: POST /api/user ───► [Панель Marzban]
     │                                                     │
     │ 6. Возврат subscription_url + QR                     │ 7. Нода готова
     ▼                                                     ▼
[Личный кабинет покупателя] ◄──── Готовый VLESS-ключ и QR-код для Happ / v2rayN
```

Благодаря изоляции логики в `LuaWorker` ядро платформы остаётся сверхбыстрым, а при сбое внешней панели Marzban упадет только конкретная изолированная транзакция, а не весь биллинг.

## Шаг 1. Подготовка панели Marzban

Убедитесь, что у вас развернута панель **Marzban** с настроенным входящим протоколом **VLESS** (с потоком `xtls-rprx-vision` и Reality).

Для интеграции понадобятся:
1. **Домен панели** (например, `marzban.yourdomain.com`);
2. **Логин и пароль суперпользователя** (создаются командой `marzban cli admin create`).

---

## Шаг 2. Подключение платёжного шлюза ЮKassa

1. Перейдите на страницу модуля [ЮKassa в каталоге SaviorBill Hub](/ru/hub/yookassa-payment) и скачайте архив `yookassa-payment.zip`.
2. В админ-панели SaviorBill откройте раздел **Провайдеры → Платёжные шлюзы → Добавить**.
3. Выберите скачанный скрипт и заполните параметры:
   - **`shop_id`**: номер магазина из личного кабинета ЮKassa;
   - **`secret_key`**: секретный ключ API (формата `live_...`);
   - **`return_url`**: адрес возврата покупателя (например, `https://billing.example.com/client/services`).
4. В личном кабинете ЮKassa в разделе **Интеграция → HTTP-уведомления** укажите адрес вебхука:
   ```
   https://billing.example.com/api/v1/payments/callback/yookassa-payment
   ```
   и отметьте событие `payment.succeeded`.

---

## Шаг 3. Установка сервисного скрипта Marzban VLESS

1. Скачайте архив скрипта со страницы [Marzban VLESS VPN Delivery](/ru/hub/marzban-vless).
2. В админке биллинга перейдите в **Автоматизация → Скрипты → Загрузить** и выберите архив.
3. В параметрах шаблона введите учётные данные вашей панели Marzban.

Скрипт полностью берет на себя рутину:
- Генерирует уникальный детерминированный логин покупателя `sb_<user_id>_<hash>`;
- Создаёт пользователя в Marzban через защищенный POST-запрос с автоматическим получением JWT-токена администратора;
- Кэширует токен авторизации в Valkey на 30 минут, избегая лишних запросов к панели;
- Назначает лимит трафика и срок действия (expire timestamp).

---

## Шаг 4. Создание тарифа и витрины цифровых товаров

Теперь свяжем платёж и выдачу в единый продукт:

1. Откройте **Каталог → Услуги → Создать услугу**:
   - Название: `VPN Нидерланды (VLESS Reality)`;
   - Длительность: `30 дней` (2 592 000 сек);
   - Тип исполнения: `Скрипт Lua (marzban-vless)`.
2. Задайте лимит трафика (например, `100 ГБ`) и стратегию сброса (`Ежемесячно`).
3. Создайте карточку продукта на главной витрине с ценой `199 ₽`.

---

## Шаг 5. Опыт покупателя: нативный Server-Driven UI

Когда покупатель оплачивает счёт через СБП, вебхук ЮKassa подтверждает платёж менее чем за секунду. Биллинг запускает действие `create`, и скрипт возвращает клиенту готовый манифест [sbuiSDK](/ru/docs/sbuisdk-components):

```lua
return {
  public = {
    subscription_url = sub_url,
    username = username,
    node_type = "VLESS"
  },
  state = "active",
  expires_at = exp
}
```

Клиентский кабинет покупателя (`SBPersonalAccountClient`) мгновенно отображает карточку с liquid QR-кодом для сканирования смартфоном и кнопкой моментального копирования ключа.

Никакой ручной отправки конфигов через Telegram или почту — всё работает автономно 24/7.
