# Заголовок первого уровня (H1)

Обычный абзац текста. Здесь проверяется комфорт чтения, высота строки и цвет текста. Например, можно использовать **жирное начертание текста**, *курсивный шрифт*, ~~зачеркнутый текст~~ или `инлайн-код на темной плашке`.

## Заголовок второго уровня (H2)

Абзац с [внутренней ссылкой на документацию](/ru/docs/quickstart) и [внешней ссылкой на репозиторий GitHub](https://github.com/UNVISLATE/SaviorBill).

### Заголовок третьего уровня (H3)

Списки различных форматов:

#### Маркированный список:
- Первый элемент списка с бирюзовым маркером
- Второй элемент списка с дополнительными пояснениями
  - Вложенный подпункт списка
  - Еще один вложенный подпункт
- Третий элемент списка

#### Нумерованный список:
1. Выполните установку через скрипт `curl -fsSL https://get.saviorbill.com | bash`
2. Настройте конфигурационный файл `.env` в корне проекта
3. Запустите сервисы командой `docker compose up -d`

## Цитаты и выноски (Blockquotes)

> **Инженерный принцип SaviorBill:**  
> Архитектура должна быть предсказуемой. Ядро биллинга не должно зависеть от стабильности внешних API, а клиентский интерфейс должен строиться декларативно на основе серверных данных.

## Таблицы данных

Таблицы автоматически оборачиваются в стильный скругленный контейнер с темным фоном шапки и аккуратными разделителями:

| Компонент | Стек | Роль в системе | Статус |
| :--- | :--- | :--- | :--- |
| **BillingCore** | Python 3.12 + FastAPI | API, транзакции, учет баланса | В продакшне |
| **LuaWorker** | LuaJIT 5.4 Sandbox | Исполнение скриптов услуг и эквайрингов | В продакшне |
| **MediaWorker** | FastAPI + FFmpeg | Конвертация WebP/WebM и S3-синк | В продакшне |
| **sbuiSDK** | TypeScript + React | Server-Driven UI рендерер манифестов | В продакшне |

## Блоки кода и подсветка синтаксиса

### Пример скрипта на Lua:

```lua
-- Пример контракта выдачи услуги
function handle(ctx)
  if ctx.action == "create" then
    local order_id = ctx.order.id
    local user_login = ctx.user.login
    
    return {
      public = {
        token = "sb_live_" .. order_id,
        instructions = "Скопируйте токен в приложение."
      },
      private = {
        internal_id = "user_" .. user_login
      },
      state = "active",
      expires_at = os.time() + 86400 * 30
    }
  end
end
```
