## Установка одной командой

Для развертывания SaviorBill на чистом Linux-сервере (Ubuntu 22.04+ / Debian 12+) выполните официальный скрипт быстрой установки:

```bash
curl -fsSL https://get.saviorbill.com | bash
```

### Что делает скрипт установки:
1. Проверяет наличие `Docker` и `Docker Compose` (при отсутствии автоматически устанавливает их из официальных репозиториев).
2. Загружает последнюю production-конфигурацию `docker-compose.yml`, `Caddyfile` и шаблон `.env`.
3. Предлагает опционально развернуть клиентскую витрину (`SBPersonalAccountClient`).
4. Генерирует криптографические секреты и поднимает сервисы через `docker compose up -d`.

---

## Доступ к сервисам после запуска

После завершения работы установщика будут доступны:
- **Панель управления администратора (Admin UI):** `https://<DOMAIN>/`
- **REST API ядра биллинга:** `https://<DOMAIN>/api/v1/`
- **Документация OpenAPI / Swagger:** `https://<DOMAIN>/api/docs`
- **Клиентский личный кабинет:** на выбранном клиентском домене.

## Системные требования

| Ресурс | Минимальные | Рекомендуемые |
| :--- | :--- | :--- |
| **Процессор (CPU)** | 1 ядро | 2+ ядра |
| **Память (RAM)** | 1 GB | 2–4 GB |
| **Диск (NVMe/SSD)** | 20 GB | 40+ GB |
| **ОС** | Ubuntu 22.04+, Debian 12+ | Ubuntu 24.04 LTS |
