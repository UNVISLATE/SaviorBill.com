# ЮKassa Payment Gateway (API v3)

Официальная интеграция эквайринга **ЮKassa** для SaviorBill по актуальному протоколу API v3.

Позволяет принимать платежи через банковские карты (МИР, Visa, Mastercard), СБП (Система быстрых платежей), SberPay, T-Pay и электронные кошельки ЮMoney.

---

### Поддерживаемые действия:
- `create` — создание платежа в ЮKassa со сценарием `redirect`. Поддерживает детерминированные ключи идемпотентности (`sb_yk_pay_<id>`) и опциональную фискализацию чеков по 54-ФЗ.
- `callback` — обработка входящего вебхука ЮKassa (`payment.succeeded`, `payment.canceled`). В целях безопасности статус всегда перепроверяется прямым server-to-server запросом к API.
- `check` — фоновая проверка статуса зависших или незавершенных платежей по расписанию биллинга.
- `refund` — оформление полного возврата средств через API возвратов ЮKassa с детерминированным `Idempotence-Key`.

---

### Настройки подключения:
1. **`shop_id`** — идентификатор магазина из личного кабинета ЮKassa.
2. **`secret_key`** — секретный ключ API (формата `live_...` или `test_...`).
3. **`return_url`** — ссылка для возврата плательщика в личный кабинет после оплаты.
4. **`send_receipt`** — отправка данных для формирования электронного чека в ФНС (54-ФЗ).
5. **`vat_code`** — ставка НДС (по умолчанию 1 — Без НДС).
6. **`payment_subject`** — признак предмета расчета (по умолчанию `service` — услуга).
7. **`payment_mode`** — признак способа расчета (по умолчанию `full_payment` — полный расчет).

---

### Настройка вебхуков в личном кабинете ЮKassa:
1. Откройте **Личный кабинет ЮKassa → Интеграция → HTTP-уведомления**.
2. Укажите URL обработчика:  
   `https://billing.example.com/api/v1/payments/callback/yookassa-payment`
3. Отметьте события:
   - `payment.succeeded`
   - `payment.canceled`
   - `refund.succeeded`
