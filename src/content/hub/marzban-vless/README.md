# Marzban VLESS VPN Delivery (Not Stable / Beta)

Модуль автоматизированной выдачи VPN-подписок по протоколу **VLESS** (с поддержкой потока `xtls-rprx-vision`) через REST API панели **Marzban**.

> [!WARNING]
> Данный скрипт помечен как **not-stable (beta)**. Рекомендуется протестировать интеграцию на тестовом инстансе Marzban перед запуском в production.

---

### Поддерживаемые действия жизненного цикла:
- `create` — авторизация в Marzban, создание пользователя с протоколом VLESS, установка лимита трафика и срока действия. Возвращает клиенту `subscription_url`.
- `renew` — продление срока действия подписки от текущего `expires_at` (или от текущего момента, если подписка была просрочена).
- `stop` / `freeze` — перевод пользователя в статус `disabled` (блокировка трафика при неуплате).
- `delete` — полное удаление пользователя из базы данных Marzban.

---

### Настройки скрипта (`manifest.json`):
1. **`marzban_domain`** — домен панели (без `https://`, например `panel.example.com`).
2. **`marzban_user`** — логин суперпользователя / администратора панели.
3. **`marzban_pass`** — пароль администратора.
4. **`data_limit_gb`** — лимит трафика в гигабайтах (0 — безлимит).
5. **`reset_strategy`** — периодичность сброса счётчика трафика (`no_reset`, `month`, `year`).

---

### Быстрое подключение в SaviorBill:
1. Перейдите в админ-панель SaviorBill: **Автоматизация → Скрипты → Добавить скрипт**.
2. Загрузите архив `marzban-vless.zip` или вставьте код из `service.lua`.
3. Создайте услугу в каталоге с типом **Скрипт Lua** и выберите данный шаблон.
4. Привяжите созданную услугу к продукту витрины.
