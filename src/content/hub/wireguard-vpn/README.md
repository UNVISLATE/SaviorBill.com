# WireGuard VPN Provider for SaviorBill

Скрипт автоматизирует выдачу пиров WireGuard. При покупке услуги покупатель мгновенно получает конфигурационный файл и векторный QR-код в клиентском кабинете.

### Настройки услуги:
1. Создайте услугу в админ-панели с типом `tiered` (тарифная сетка).
2. Загрузите данный Lua-скрипт в раздел LuaWorker.
3. Привяжите скрипт к услуге.
